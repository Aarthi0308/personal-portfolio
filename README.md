
# Personal Portfolio Website

## About the Project
This is a responsive, one-page personal portfolio website built using HTML5 and CSS3. It showcases my introduction, technical skills, projects, and contact links.

## Features
- Semantic HTML5 structure
- Responsive design for desktop, tablet, and mobile
- CSS Flexbox and Grid layouts
- About Me section
- Technical Skills section
- Projects showcase
- Contact links for Email, LinkedIn, and GitHub

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Structure
my-portfolio/
├── index.html
├── style.css
└── README.md

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Aarthi0308/my-portfolio.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

## Design Decision
I chose a clean layout with purple accents and card-based sections to improve readability. CSS Grid and Flexbox help organize content, while media queries make the website accessible across different screen sizes.
